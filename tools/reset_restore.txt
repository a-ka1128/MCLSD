Last Stardust — 초기화 후 다시 등록하는 것들
====================================================================
이 파일이 「laststardust.dat 이 갖고 있던 설정」의 유일한 사본이다.
그 파일을 지우면 아래 값들은 **월드 어디에도 안 남는다** — 자석석과
성벽은 그대로인데 등록만 사라진다.

좌표 출처: 2026-08-13 laststardust.dat 실측.
값을 바꿨으면 여기도 같이 고칠 것. reset_open.ps1 이 이 파일을 그대로
화면에 뿌리므로, 여기가 낡으면 초기화 직후에 낡은 좌표를 붙여넣게 된다.
====================================================================

── 서버를 켜고 채팅창에 한 줄씩 ──

/time set 0
/sanctuary here
/wall radius 60
/relic altar shared 5887 85 5877
/riftnode spawn 잿빛협곡


⚠️ 예전에는 `/riftnode add 잿빛협곡` 이었다. add 는 «장부에만» 넣어서
   실물이 없는 어둠이 생긴다 — 2026-08-13 점검에서 실물 검증이 없는 유일한
   시스템으로 지적된 그것이다. spawn 은 좌표를 굴려 예고까지 하고, 플레이어가
   찾아가 부술 수 있다. add 는 이제 쓰지 않는다.

※ 봉화 폐허 6곳은 **따로 칠 게 없다.** /sanctuary here 가 끝나면 2초 안에
   자동으로 흩어진다. /ruin 으로 확인만 하면 된다.


── 몸이 그 자리에 있어야 하는 것 ──

/sanctuary here      → 5913, 76, 5897 에 서서.
                       (좌표 인수 형태가 없다. tp 로 가서 친다:
                        /tp @s 5913 76 5897)

/town hearth set     → 대장간 4단계 「귀환의 요람」 자리에 서서.
                       한 번도 안 찍혀 있었다 — 복구가 아니라 첫 지정이다.
                       안 찍으면 귀환석이 성역으로 보낸다(고장은 아님).

/setworldspawn       → 비행선 위에서. 새로 들어오는 사람이 여기서 시작한다.


── 선택 ──

/town anchor workshop   → 5930, 85, 5872 (성역 기준 +17, +9, -25)
                          구조물을 안 세우기로 했으므로 안 해도 된다.


── 다시 등록 «안» 해도 되는 것 ──

성벽 모양·진격 각도       kubejs/server_scripts/ls_config.js
상점 품목·가격            moddev .../shop/ShopCatalog.java
NPC 프리셋                kubejs/data/easy_npc/...
세워 둔 건물·전송석·NPC   월드와 easy_npc_index.dat / waystones.dat

전부 laststardust.dat 밖에 있어서 그대로 남는다.


── 확인 ──

/relic altar    공용 제단이 ✔ 로 뜨는지 (좌표까지 같이 나온다)
/sanctuary info 성역·위협도·노드·금고를 한 줄로
/wall           반경 60 · 스폰 거리 93칸 · 시뮬레이션 거리 경고 없는지
/town           마을 화면이 뜨는지

위협도가 0, 「n일차」가 1, 첫 공세가 아직 안 끝난 상태여야 정상이다.
