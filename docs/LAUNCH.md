## A. 열기 전에 반드시 (블로커 5)

### A-1. 🔴 화이트리스트가 꺼져 있다

`server/server.properties` 가 지금 이렇다:

```
white-list=false
enforce-whitelist=false
online-mode=true
max-players=8
```

**주소만 알면 아무나 들어온다.** 8인 지인 서버에 이 상태로 열면 안 된다.

```
white-list=true
enforce-whitelist=true
```
로 바꾸고 **`/whitelist add <닉>` 을 인원수만큼** 미리 넣어 둔다.
`enforce-whitelist=true` 까지 켜야 **이미 접속 중인 비허용자도 끊긴다.**

### A-2. 🔴 월드 리셋

지금 월드는 **시험판**이다 — 오늘 하루만 보스를 여덟 번 소환하고 격노를 걸었다 풀었고
`/dummy` 더미가 곳곳에 서 있다. 리셋은 이미 예정돼 있다(2026-08-06 확인).

**리셋에 묶여 있는 것들이 있다:**

| | |
|---|---|
| `ls_migrate.js` 삭제 (627줄) | **순서: 리셋 → 한 판 돌려보고 → 그다음 삭제** |
| 제단 자연생성 (가호별 9~10곳) | 월드젠이라 리셋 때만 심을 수 있다 |
| 균열 노드 배치 | 「능동 반격」이 이걸 기다리는 중 |

### A-3. 🟡 성역 좌표 지정

새 월드에는 성역이 없다. **없으면 공성·관문·봉화가 통째로 안 돈다.**

```
/sanctuary set
```

첫 세션 시작 지점을 정한 뒤 곧바로 찍는다.

### A-4. 🟡 백업이 실제로 도는지

`server/backup.bat` 는 **있다.** 다만 **자동 실행이 걸려 있는지는 확인 안 됐다** —
작업 스케줄러에 등록돼 있는지, 어디에 몇 개까지 쌓는지.

리셋 직후 **첫 백업이 실제로 파일로 떨어지는 것**을 눈으로 한 번 봐야 한다.
「돌고 있다고 생각했는데 아니었다」가 제일 비싼 실패다.

### A-5. 🟡 접속 경로

포트포워딩(25565) · 공인 IP 또는 도메인 · 방화벽.
`difficulty=hard` 는 그대로 둔다 — **오늘의 모든 수치가 Hard 기준으로 측정됐다**
(`mobAttack` 이 난이도 배수 ×1.5 를 탄다 — `BLESSING.md`).

## B. 첫 세션 (온보딩 30분)

정해진 흐름은 이미 있다:

```
접속 → 프롤로그 자동 재생(약 30초) → /fate 선택 화면 → 시작 키트
     → 첫 공성 격퇴 → 별의 파편 1 → 제단에 바침 → 유물 획득(1성)
```

- **가호는 8종이 각자 하나씩** — 겹치면 못 고른다. 미리 정해 두는 편이 낫다
- 프롤로그 다시 보기: `/lsrelic prologue`
- 유물 카드 12종은 **디스코드에 이미 게시**돼 있다

**⚠️ 오프닝 「별이 꺼지는 밤」 대본은 아직 없다**(`TODO.md` D절).
없어도 서버는 돌지만, 첫 세션의 분위기를 잡는 물건이라 여기만 손으로 메꿔야 한다.

## B-2. 🔴 「보여주는 화면」은 있는데 **「보이는 세계」가 없다**

UI 쪽은 오히려 잘 갖춰져 있다 — 마을 화면(**M**) · `/bless` 창 · 사이드바 `희망`/`위협` ·
봉화 점화 물결 · 보스 예고 테두리 파티클 · 유물 툴팁과 전승 2행 · 디스코드 카드 12종.

**빈 건 월드 쪽이다.** 시스템이 전부 숫자와 명령으로만 존재한다.

### ① 성역이 «좌표 한 점»이다 — 제일 큰 빈칸

공성의 판돈이 **성벽 내구도 3000 + 방벽Lv×1000** 인데, **그 성벽이 물리적으로 없다.**
지금은 반경 24 의 보이지 않는 선이고, 몹은 거기서 밀려나며 «무언가»를 두드린다.

코드는 처음부터 **누군가 짓는다는 전제**로 쓰였다:

```js
const WALL_DEFAULT_R = 24     // 성벽 반경 기본값 (실제 성벽에 맞춰 /wall radius 로 조정)
// 신호기 등 중심물은 장식 — 체력은 성벽 자체에 있다. 방벽(ramparts) 레벨 = 성벽 내구도.
```

**리셋하면 맨땅에서 시작한다.** 성벽을 짓고 `/wall radius <n>` 으로 맞추지 않으면
「밤새 보이지 않는 벽을 지킨다」가 된다 — 공성이 이 서버의 중심 루프인데.

> 최소한: 반경 24 짜리 벽 하나. 모양은 `ls_config.js` 에서 원형/정사각을 고른다.
> 문·망루 같은 건 나중에 붙여도 되지만 **벽 자체는 첫 공성 전에 있어야 한다.**

### ② 마을 16단계가 월드에서 하나도 안 자란다

4트랙(방벽 ▦ · 공방 ⚙ · 성소 · 구역) × 4레벨 = **16단계**. 금고를 붓고 레벨을 올려도
**화면 속 숫자와 효과만 바뀌고 세계는 그대로다.**

이 서버의 서사가 「재건」인데 **재건이 안 보인다.** 레벨마다 블록 몇 개씩만 놓아도
(방벽 = 벽이 두꺼워짐 · 공방 = 모루/화로가 늘어남 · 성소 = 제단이 커짐 · 구역 = 집이 생김)
전혀 다른 물건이 된다.

> 구현은 어렵지 않다 — 레벨업 훅에서 `/fill`·구조물 붙여넣기 한 번이면 된다.
> **정해야 할 건 「무엇이 자라는가」이지 「어떻게 자라는가」가 아니다.**

### ③ 유물 제단이 lodestone 한 칸

가호별 9~10곳. 지금은 **손으로 짓고 `/relic altar <가호>` 로 좌표를 등록**해야 한다.
리셋 때 데이터팩 구조물로 심으면 `/relic altar` 자체가 사라진다(`TODO.md` C절에 방법 있음).

**건물은 하나만 만들어 9~10번 재사용하고 가호 색 블록만 바꾸는 게 낫다** —
일이 훨씬 적고, 「같은 양식의 제단」이 세계관상 더 맞는다.

### ④ 공용 시각 기호 3종 · 최종문 실루엣

8각 별 / 꺼진 등불 / 검은 덩굴 — **어디에도 안 쓰이고 있다.** 이게 있어야
「여긴 별지기의 자리」와 「여긴 삼켜진 곳」이 말 없이 갈린다.
최종문(어둠의 첨탑)은 지평선에 보이는 목표물이라 **첫날부터 보여야 값을 한다.**

### ⑤ 유물 모델 둘이 «자리 맡기»다

헤카테·하르모니아는 **같은 낫을 재채색한 것**이다.
`models/item/*.json` + `textures/item/*.png` **두 파일만 덮으면 교체된다** — 코드는 안 바뀐다.

## C. 열고 나서 확인할 것 — **여기가 진짜 목록이다**

혼자서는 더 못 잰다. `⚠️ 실전 미검증` 이 **16개** 남아 있고, 대부분 4인이 있어야 한다.

### C-1. 🔴 파나케이아 + 케이론 = 14 HPS

**남은 것 중 제일 큰 위험.** 힐러 둘이 겹치면 파티가 안 죽는다 —
그러면 오늘 맞춘 보스 수치가 통째로 무의미해진다.
둘 다 있는 판을 **한 번은 반드시** 겪어야 한다.

### C-2. 보스 난이도 — 셋이 물러진 채로 남아 있다

| 5성 원거리(80HP) 기준 | 예전 | 지금 |
|---|---:|---:|
| 강철거인 | 1.4대 | 2.2대 |
| 이그니스 | 2.7대 | 3.9대 |
| 건틀렛 | 3.0대 | **3.1대** ← 복원됨 |
| 괴물 | 2.1대 | 3.3대 |

`dmg%` 로는 더 못 올린다(`TEST-PLAN.md` 3-C). 남은 손잡이는 **보스 체력**뿐인데
그건 「4명 60초」 설계선을 건드린다. **4인 한 판을 겪고 정한다.**

전투 기록계가 판마다 「목표 60초 → 권장 체력 N」을 스스로 뽑아 주니 그 숫자를 쓰면 된다.

### C-3. 🔴 강철거인이 1성을 평타 한 대에 죽인다

T1 보스인데 평균 37.1 · 최대 67.5 다. 1성 체력이 32~40 HP 니 **근접·원거리는 원콤**이고
탱커도 1.08대다. `dmg 100` 으로도 그렇다.

느리고 예고가 큰 보스라 실전에선 대부분 피하겠지만, **첫 관문에서 원콤이 나면
배울 기회가 없다.** 4인이 실제로 어떻게 겪는지 보고 정한다.

### C-4. B절 5종 — 한 번도 실전에서 안 돌았다

공성 예고 단계화 · 봉화 점화 물결 · 희망 게이지 · 공성 몹 티어 교체 · 보스 기믹 5종.

### C-5. 5성 2단 — 8종 미검증

4종은 실측 완료(이지스·타이탄·펠리온·셀레스티아). 남은 여덟은
**처치**(스틱스·헤스페로스) · **패링 타이밍**(아드라스테이아) ·
**아군 필요**(파나케이아·바르비톤) · **눈으로 보면 끝**(게볼그·솔라리스·시리우스).

### C-6. 주간 금고 · 균열 서약

명령과 훅은 전부 확인됐다. 남은 건 **여럿이 도는 판에서**
공성 적립이 관전자 빼고 전원에게 가는지, 서약 몹 강화가 파티 전체에 걸리는지.

## 요약 — 순서대로

```
1. 화이트리스트 켜고 인원 등록          ← 이게 제일 급하다
2. 월드 리셋
3. /sanctuary set
4. 성벽을 «짓고» /wall radius 로 맞춘다  ← 없으면 공성이 성립하지 않는다
5. 유물 제단 9~10곳 (또는 구조물로 심기)
6. 백업이 실제로 도는지 눈으로 확인
7. 한 판 돌려본 뒤 ls_migrate.js 삭제
8. 열고, C절을 겪으면서 채운다
```

**4·5 는 코드가 아니라 손으로 짓는 일이다.** 오늘까지의 작업이 전부 「숫자가 맞는가」였는데,
**남은 큰 덩어리는 「보이는가」 쪽이다.**

**C절은 열기 전에 못 채운다.** 그게 이 서버의 남은 미지수 전부이고,
혼자 재는 것으로는 여기까지가 끝이다.
