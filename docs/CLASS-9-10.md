## 1. 「헤카테」 — HECATE

| 항목 | 값 |
|---|---|
| 아이콘 · 색 | 🌑 · `0x17A2A2` (틸) |
| 별칭 · 역할 | 세 갈래 길의 주인 · **저주·군중제어** |
| 유물 | **클레이스** (경계의 문 열쇠) |
| 웹훅 키 | `hecate` |
| 아트 | `discord/art/Hecate.png` ✅ 있음 |
| 파일 | `discord/post_hecate.py` |

> 어둠과 경계의 문을 다스리는 자의 가호.
> 적에게 저주의 낙인을 새기고, 그 힘을 주변으로 퍼뜨려 적의 움직임과 힘을 서서히 빼앗는다.
> 헤카테의 밤이 드리우는 순간 모든 저주가 절정에 이르며, 적은 회복마저 잃은 채 깊은 어둠 속에 잠긴다.

| 슬롯 | 이름 | 효과 | 쿨 |
|---|---|---|---|
| 패시브 | 저주의 낙인 | 평타 적중 시 낙인 1중첩(최대 5, 5초) · 중첩당 대상이 받는 피해 +3% | — |
| 기본 R | 역병의 손길 | 전방 8칸 부채꼴 · 낙인 2중첩 + 쇠약(공격력 −20%) 4초 | 6초 |
| 이동 V | 경계의 문 | 바라보는 방향 10칸 지점으로 문을 열어 이동 · 나온 자리 3칸 내 적에게 낙인 1중첩 | 8초 |
| 추가 C | 전이 | 대상의 낙인을 주변 8칸 적 최대 4명에게 복제 · 복제된 적 둔화II 4초 | 15초 |
| 궁극 X | 헤카테의 밤 | 반경 12칸 10초 · 안의 적 낙인 5중첩 고정 · **받는 치유 −100%** · 실명 + 이동속도 −30% | 90초 |

**설계 의도** — 「낙인을 쌓는다 → 주변으로 퍼뜨린다 → 한꺼번에 절정에 올린다」가 한 줄로 이어지는
직업. 기존 8종에 없던 *디버프 전담* 자리를 채운다 (CLASS-RESEARCH §7 「비었고 후순위」의 디버프 #14).

### ⚠️ 구현하면서 갈린 것 — 구현 쪽으로 통일 (2026-08-09, 유저 결정)

카드가 먼저 있었고 코드가 나중에 붙는 사이 사양이 갈렸다. **이 표가 실제로 도는 값이다.**

| | 위 원안 | **실제 구현** |
|---|---|---|
| 별칭 | 세 갈래 길의 주인 | **횃불을 든 자** ← 「삼거리」가 명시적으로 반려됐다 |
| 역할 | 저주·군중제어 | **약화·지원** |
| 유물 | 클레이스 (경계의 문 열쇠) | **헤스페로스** (낫) |
| 아이콘 | 🌑 | 인게임 **☽** / 디스코드 🌑 (아래 ※) |
| 패시브 | 낙인 5중첩 · 5초 | 저주 5중첩 · **8초** · **보스는 상한 8** |
| R | 역병의 손길 · 8칸 · −20% 4초 · 6초 | **재의 채찍** · 6칸 · **−25% 6초** · **10초** |
| V | 경계의 문 — 10칸 순간이동 | **재의 결계** — 뒤로 도약 + **출발 지점** 속박 1.5초 |
| C | 전이 · 4명 + 둔화II | **연좌** · **8마리** · 중첩 소모 없음 |
| X | 낙인5 + 치유−100% + 실명 + 이속−30% · 90초 | 최대중첩 + 회복차단 + **받는피해+10% + 공격력−20%** · **60초** |

**왜 바뀌었나**
- **별칭** — 에레보스가 이미 「그림자에 **선 자**」라 구조가 겹쳤고, 유저가 「삼거리」를 반려했다.
- **보스 상한 8** — 「강한 자를 끌어내린다」가 이 직업의 정체성인데 원안엔 그 축이 없었다.
- **V** — 원안은 순간이동인데, 이동기의 값어치는 「쫓아오는 것을 끊는 것」이라 속박을 **출발 지점**에
  남기는 쪽이 앞뒤가 맞는다. 도착한 빈 땅을 묶으면 아무 일도 안 일어난다.
- **X 의 방어구 무시 20% 를 뺐다** — 마크 잡몹은 방어도가 0~2 라 실제 효과가 **+0.3%** 인데
  중장갑 보스에겐 **+13%** 로 튄다. 진폭 40배짜리 죽은 줄이라 공격력 감소로 바꿨다.
  (「받는 피해 +10%」는 기존 `WeaknessHandler` 표식을 그대로 쓴다 — 같은 일을 두 번 구현하지 않으려고.)
- **C 는 중첩을 «복사»하고 소모하지 않는다** — 터뜨려 없애면 「파티 버프를 내 딜과 맞바꾸는」
  함정 선택이 된다. 친구끼리 하는 서버에서 그런 함정은 재미가 아니라 실수다.

※ **아이콘이 두 곳에서 다른 건 의도다.** 마크 기본 폰트엔 이모지 글리프가 없어 네모로 뜨므로
  인게임은 BMP 기호만 쓴다(☽ · 하르모니아 ♫). 디스코드는 이모지가 잘 나온다.
  기존 8종도 이미 그렇다(오리온 🏹 / ➶).

## 2. 「하르모니아」 — HARMONIA

| 항목 | 값 |
|---|---|
| 아이콘 · 색 | 🪢 · `0xE86A9A` (로즈) |
| 별칭 · 역할 | 흩어진 것을 묶는 자 · **버프·지휘** |
| 유물 | **케스토스** (엮는 띠) |
| 웹훅 키 | `harmonia` |
| 아트 | `discord/art/Harmonia.png` ❌ **아직 없음** |
| 파일 | `discord/post_harmonia.py` |

> 흩어진 것들을 하나로 엮는 자의 가호.
> 상처를 덮는 대신 사이를 잇는다. 선율이 닿는 자리에서 아군의 걸음이 서로 맞물리고, 따로 싸우던 이들이 하나의 진형이 된다.
> 케스토스가 마지막 매듭을 조이는 순간 모든 굴레가 끊기고, 그 화음이 닿는 곳까지 누구도 흐트러지지 않는다.

| 슬롯 | 이름 | 효과 | 쿨 |
|---|---|---|---|
| 패시브 | 공명 | 주변 8칸 아군 이동속도 +10% · 아군이 적 처치 시 8초간 공격력 +5%(최대 3중첩) | — |
| 기본 R | 고양의 선율 | 전방 10칸 아군 공격속도 +25% 4초 + 넉백 저항 | 10초 |
| 이동 V | 엮인 걸음 | 전방 위로 도약 · 착지 지점 4칸 내 아군에게 신속II 3초 | 8초 |
| 추가 C | 결속의 매듭 | 지점에 매듭 12초 · 반경 6칸 아군 받는 피해 −15% + 스킬 쿨 초당 −2% | 25초 |
| 궁극 X | 만상의 화음 | 24칸 내 전 아군 10초간 공격력 +30% · 이동속도 +25% · **디버프 해제 후 3초간 재부여 면역** | 90초 |

**설계 의도 세 가지** (구현할 때 이게 안 지켜지면 직업의 존재 이유가 사라진다):

1. **히기에이아와 겹치지 않는다.** 치유·보호막·부활을 **하나도 넣지 않았다.** 히기에이아가 서포트의
   *회복* 절반, 하르모니아가 *강화* 절반을 갖는다. 둘이 같은 파티에 있어도 역할이 안 먹힌다.
2. **헤카테의 대척점이다.** 궁극의 디버프 해제 + 재부여 면역 3초가 헤카테의 저주 축적을 정면으로
   끊는다. 저주를 쌓는 쪽과 끊는 쪽이 동시에 생겨서 공성·PvP 에 읽는 재미가 붙는다.
3. **CLASS-RESEARCH §6 의 「버퍼 분화(#19) → 쿠 훌린 흡수」안과 경합한다.** 둘 다 하면 중복이다.
   하르모니아를 구현하면 그 흡수안은 **폐기**해야 한다.

### 이름 후보 — 왜 하르모니아인가

처음에는 「니케」(승리·지휘, 유물 「살핑크스」)로 만들었다가 유저가 다른 이름을 원해 교체했다.
검토한 후보와 탈락 사유를 남긴다 — 안 그러면 다음에 같은 논의를 처음부터 한다.

| 후보 | 성격 | 판정 |
|---|---|---|
| **하르모니아** | 조화·결속. 버프가 「아군을 엮는다」는 결이라 역할을 이름이 설명한다 | ✅ **채택 (유저 결정)** |
| 엘피스 | 희망. `ls_hope.js` 희망 게이지와 이름이 직결돼 시스템 연동 여지가 컸다 | 미채택 |
| 오르페우스 | 리라·노래. 로어 임팩트 최고지만 신화 결말이 *실패*라 강화 컨셉과 어긋남 | 미채택 |
| 아스트라이아 | 별의 처녀. 제목(Last Stardust)과 잘 붙지만 오리온·우라니아와 별 테마 3중복 | 미채택 |
| 니케 | 승리·개선. 원안. 스킬명이 전부 전쟁 어휘(돌격 나팔·승리의 깃발·개선)였다 | 교체됨 |

**이름을 바꾸면서 스킬명 5개도 전부 갈았지만 수치와 쿨타임은 한 글자도 안 건드렸다.**
이름 바꾸는 김에 밸런스까지 흔들면 나중에 실측할 때 뭐 때문에 어긋났는지 못 가리기 때문이다.

## 5. 디스코드 카드 게시 방법

기존 8종과 완전히 동일하다. 데이터만 파일에 있고 전송·서식·옛 글 교체는 `lsdiscord.py` 가 한다.

```powershell
# 1) 웹훅 URL 넣기 — 둘 중 하나
#    · 환경변수  LSD_WEBHOOK_HECATE / LSD_WEBHOOK_HARMONIA
#    · discord/webhooks_local.py 의 WEBHOOKS["hecate"] / ["harmonia"]   (git 에 안 올라감)
# 2) 게시
py post_hecate.py          # 하나만
py post_harmonia.py
py post_classes.py         # 10종 전부 (웹훅 빈 클래스는 조용히 건너뜀)
```

- **웹훅 URL 자체가 인증이다.** 소스에 박지 말 것 — `webhooks.py` 주석 참조.
- `post_classes.py` 의 `MODULES` 끝에 `post_hecate` · `post_harmonia` 가 등록돼 있다(총 10).
- 다시 올리면 `posted_ids.json` 에 기록된 옛 글을 먼저 지운다. **두 직업은 아직 한 번도 게시된 적이 없다**
  (`posted_ids.json` 에 키 없음 — 2026-08-08 확인).
