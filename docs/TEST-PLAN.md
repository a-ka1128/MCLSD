## 0. 시작 전 (3분) — 건너뛰지 말 것

```

```

**월드에 지난 세션 시험 소환 보스 5기가 남아 있다.** 히드라·프로스트모·유령기사·우르가스트·

- `Loaded 24/24 KubeJS server scripts ... with 0 errors`

## 1. 제일 먼저 걸어둘 것 — 격노 «안 걸려야 정상» 시험 (10분, 방치)

**이게 이번에 고친 것 중 제일 중요하다.** 07-31 로그에서 **접속자 0명인데 보스가
+200% 까지 올라가 있었다.** 교전 판정이 아예 없어서 엔티티를 본 순간부터 시계가 돌았다.

실전 피해: 트와일라잇 구조물 보스나 도망친 보스가 로드된 청크에 서 있기만 해도 조용히
세지고, 나중에 그 앞을 지나간 사람이 **영문 모르고 한 방에 죽는다.**

시간이 걸리니 **먼저 걸어두고 2·3번을 하는 동안 흐르게 둔다.**

```
/lsgimmick ignis summon
```

소환한 뒤 **48칸 밖으로 물러나서 건드리지 않는다.** 10분 뒤:

```
/enrage status
```

| 봐야 할 것 | 판정 |
|---|---|
| 「교전 0초 · +0%」 또는 「대기 N초」 | ✅ **고쳐졌다** |
| 「교전 600초 · +10%」 이상 | ❌ 아직 벽시계로 센다 — `ls_enrage.js` `enEngaged()` 확인 |

그다음 **붙어서 실제로 때리며** 8분을 채우면 걸려야 한다. 8분을 기다리기 싫으면:

```
/enrage now 5
/enrage status     ← 「교전 N초 · +50%」
/enrage clear
```

> `/enrage now` 는 이미 검증됐다(07-31, 이그니스 14.0 → 22.4 → 14.0). **이번에 볼 건
> 「안 걸리는 것」이다.** 없던 기능이 아니라 없던 조건을 확인하는 것이라 헷갈리기 쉽다.

## 3. 혼자 · 시험 소환 (30분) — **셰이더 켠 밤에**

어휘부터. 셰이더/밤/군중에 파티클이 묻히는지가 이 시험의 절반이다.

```
/lsgimmick test danger      ← 빨강, 피해라
/lsgimmick test stack       ← 노랑, 뭉쳐라
/lsgimmick test spread      ← 보라, 흩어져라
```

그다음 관문 보스. 각각 `summon` → `window`(있으면) → `now`:

| 보스 | 명령 | 봐야 할 것 |
|---|---|---|
| T1 강철거인 | `/lsgimmick summon` → `window` → `now` | 초록(취약 창 2.9초) · 빨강 장판 반경 4.5 |
| T2 이그니스 | `/lsgimmick ignis summon` → `now` | 노랑 결계 **바깥만** 피해. 계속 때려 반격 구간(파랑) |
| T4 괴물 | `/lsgimmick monstrosity summon` → `now` | 보라 → 2.5초 뒤 노랑. **두 어휘가 정반대** |
| 최종 리치 | `/lsgimmick lich summon` → `now` | 파랑(삼킴 무적) + 노랑 |
| 공성 선봉 | `/lsgimmick vanguard summon` → `now` | 반경·예고가 **T1 과 똑같이** 보이나 (피해만 6) |

**3-1. 탐험 보스 4종의 숨은 규칙** — 먼저 규칙을 띄워놓고 시작:

```
/lsgimmick explorer
```

넷 다 바닐라 `/summon` 으로 부른다. **프로스트모가 제일 중요하다:**

```
/summon mowziesmobs:frostmaw ~ ~ ~
```

→ **시리우스(활)로 쏴 본다.** 화살 착탄 경고가 뜨고, **피해가 0 이어야 한다.**
이건 코드(javap)로만 확인된 상태다. 사실이면 **시리우스는 이 보스에게 아무것도 못 한다** —
별빛 사격·유성 사격·화살 폭풍이 전부 진짜 `Arrow` 엔티티라서 우회로가 없다. 밸런스 결정거리다.

나머지 셋:

```
/summon twilightforest:hydra ~ ~ ~          ← 벌린 입에만 초록. 20칸 밖은 무피해
/summon twilightforest:knight_phantom ~ ~ ~ ← 돌진 중에만 초록 (아니면 방어도 5배)
/summon twilightforest:ur_ghast ~ ~ ~        ← 발작 중 액션바 (색 안 씀)
```

끝나면 반드시:

```
/lsgimmick clear
```

## 4. 2명 필요 — T3 건틀렛 하나뿐

```
/lsgimmick gauntlet summon
/lsgimmick gauntlet now
```

**1인으로는 원만 뜨고 피해가 없다. 버그가 아니라 정의상 그렇다** — 판정이 「원 안이냐」가
아니라 「몇 명이 같이 있냐」다. 원 안이면 피해로 만들면 그건 그냥 빨강이고 어휘가 하나 준다.

둘이 **붙어 서서** `now` → 둘 다 피해 7. **떨어져 서서** `now` → 둘 다 무피해.
2페이즈(체력 50%)는 보라 + 보스 발밑 빨강 동시 = 어휘 조합의 첫 적용점.

## 5. 실전 한 판 — 여기서만 알 수 있는 것

### 5-1. 보스 체력 4종 (4명·60초 목표)

**초시계도 계산기도 필요 없다.** 보스가 죽으면 스스로 낸다:

```
▣ 이그니스 처치 · 87.4초 · 4명 · 체력 7000 (실측 DPS 80)
목표 60초 → 권장 체력 4806   /bossdiff abs cataclysm:ignis 4806
```

운영 권한(2) 있는 사람에게만 보인다. **인원이 4명이 아니면 경고가 같이 뜬다** — 그 값을
그대로 넣으면 어긋난다. 다 재고 나면 `/bossdiff export`.

시간은 벽시계가 아니라 **교전으로 인정된 틱**이다. 죽고 돌아오는 시간은 안 센다.

### 5-2. 공성 한 판

- 위협도·성벽 HP·보상이 **재접속 후에도 남나** (이관 4단계 실전 검증)
- 마지막 웨이브에 **「균열의 선봉」** 이 나오나
- 예고 세 박자가 하루에 걸쳐 도나
- 격퇴/패배 후 **희망 게이지**가 움직이나

### 5-3. 유물 밸런스

```
/dummy
```

- **⭐ 시리우스 재측정 (2026-08-04 폭발 ×0.75 조정 후)** — 4판 이상 모을 것

  유성 사격 폭발이 살아난 뒤 시리우스가 78.9 → 104.8 로 튀어 폭발을 12.71 → 9.53 으로 내렸다.
  **지속 97.9 를 겨냥한 값인데 궁극기 몫(15.9)이 한 판씩의 추정이다.** 이 무기는 궁극기가
  ±20% 로 흔들려 「4판 이상 모아서 판단」이 원칙이다(`StarBow` 주석).

  | 봐야 할 것 | 기대 |
  |---|---|
  | 유성 사격 | 18타 · 평균 **75 안팎** (조정 전 99~103) |
  | 시리우스 지속 | **97 안팎** — 솔라리스 97.0 · 셀레스티아 99.1 사이 |

  궁극기 횟수를 적어둘 것 — 45초 쿨이라 60초 안에 1~2회로 갈리고, 그 차이가 15 DPS 다.

- **⭐ 스틱스 ×1.15 실측 (2026-07-31 변경, 최우선)** — 아이템 공격력 1.225 → 1.409.
  60초씩 세 번 재고 `DECISIONS.md` 1절의 표를 덮어쓴다:

  | 재는 법 | 예측 | 원래 요구 |
  |---|---|---|
  | 백어택 ✗ · 크리 ✗ (바닥) | 53.3 | 50 이상 |
  | 백어택 ✓ · 크리 ✗ | 59.9 | — |
  | 풀딜 (백어택+크리) | 68.0 | **70 이하** |

  세 번째가 70 을 넘으면 되돌리거나 배수를 낮춘다. 실측 후 `calc_power_ratio.py` 의
  스틱스 **(기본치, 실측) 쌍을 같이** 고칠 것 — 한쪽만 고치면 보정상수가 흡수해 안 움직인다.
- **⭐ 몹 스케일링 C 확인** — 늑대·북극곰을 잡아 보고 **스케일링이 안 붙어야** 한다(좀비는 붙는다).
  로그에 `ls_mobscale:isMonster` 경고가 뜨면 다리가 실패하고 조용히 옛 동작으로 돌아간 것이다.
- **⭐ 부푼 몹 청소 — 돌아다니면서 가끔** `/mobscale fix`

  재시작마다 복리로 붙던 버그(D절 7)가 남긴 개체들이다. 07-31 시험 서버에서 **로드된
  청크 67기 중 30기가 부풀어 있었다.** 고친 코드는 스폰 훅에서 자동 복구하지만 구멍이 셋 있다:
  ① 티어 0 이면 훅이 일찍 return 한다 ② **늑대·철골렘·벌은 이제 비적대라 훅이 아예 안 본다 —
  그것들은 이 명령으로만 돌아온다** ③ 청크가 로드돼야 훅이 온다.

  그래서 **성역·마을·자주 가는 곳을 한 바퀴 돌면서 몇 번 실행**할 것. 여러 번 돌려도 안전하다
  (두 번째부터는 «0기»가 나온다). 관문을 깬 뒤에도 한 번 — 티어가 바뀌면 기준값도 바뀐다.
- **유물 ×1.8** — 네더라이트 검 60초 vs 1성 유물 60초 (성역 축복 안에서 통일)
- **부활 규칙** — 죽어보고 5초 무적 + **원거리 유물로** −25% 확인
  (근접만 보면 안 된다. 예전에 원거리·스킬이 통째로 새어나가고 있었다)
- ⚠️ **파나케이아는 더미로 재지 마라** · ⚠️ **솔라리스는 배율로 못 고친다**
  — 이유는 `DECISIONS.md` 1절 하단
