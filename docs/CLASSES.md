**설계 의도** — 「낙인을 쌓는다 → 주변으로 퍼뜨린다 → 한꺼번에 절정에 올린다」가 한 줄로 이어지는

### ⚠️ 구현하면서 갈린 것 — 구현 쪽으로 통일 (2026-08-09, 유저 결정)

카드가 먼저 있었고 코드가 나중에 붙는 사이 사양이 갈렸다. **이 표가 실제로 도는 값이다.**

| | 위 원안 | **실제 구현** |
|---|---|---|
| 별칭 | 세 갈래 길의 주인 | **횃불을 든 자** ← 「삼거리」가 명시적으로 반려됐다 |
| 역할 | 저주·군중제어 | **약화·지원** |
| 유물 | 클레이스 (경계의 문 열쇠) | **헤스페로스** (낫) |
| 아이콘 | 🌑 | 인게임 **☽** / 디스코드 🌑 (아래 ※) |
| 패시브 | 낙인 5중첩 · 5초 | 저주 5중첩 · **8초** · **보스는 상한 8** |
| R | 역병의 손길 · 8칸 · −20% 4초 · 6초 | **재의 채찍** · 6칸 · **−25% 6초** · **10초** |
| V | 경계의 문 — 10칸 순간이동 | **재의 결계** — 뒤로 도약 + **출발 지점** 속박 1.5초 |
| C | 전이 · 4명 + 둔화II | **연좌** · **8마리** · 중첩 소모 없음 · **대상 7.0 / 옮겨붙는 쪽 3.5 피해** |
| X | 낙인5 + 치유−100% + 실명 + 이속−30% · 90초 | 최대중첩 + 회복차단 + **받는피해+10% + 공격력−15%** + **지대 초당 2.2** · **60초** |

**왜 바뀌었나**
- **별칭** — 에레보스가 이미 「그림자에 **선 자**」라 구조가 겹쳤고, 유저가 「삼거리」를 반려했다.
- **보스 상한 8** — 「강한 자를 끌어내린다」가 이 직업의 정체성인데 원안엔 그 축이 없었다.
- **V** — 원안은 순간이동인데, 이동기의 값어치는 「쫓아오는 것을 끊는 것」이라 속박을 **출발 지점**에
  남기는 쪽이 앞뒤가 맞는다. 도착한 빈 땅을 묶으면 아무 일도 안 일어난다.
- **X 의 방어구 무시 20% 를 뺐다** — 마크 잡몹은 방어도가 0~2 라 실제 효과가 **+0.3%** 인데
  중장갑 보스에겐 **+13%** 로 튄다. 진폭 40배짜리 죽은 줄이라 공격력 감소로 바꿨다.
  (「받는 피해 +10%」는 기존 `WeaknessHandler` 표식을 그대로 쓴다 — 같은 일을 두 번 구현하지 않으려고.)
- **C 는 중첩을 «복사»하고 소모하지 않는다** — 터뜨려 없애면 「파티 버프를 내 딜과 맞바꾸는」
  함정 선택이 된다. 친구끼리 하는 서버에서 그런 함정은 재미가 아니라 실수다.

※ **아이콘이 두 곳에서 다른 건 의도다.** 마크 기본 폰트엔 이모지 글리프가 없어 네모로 뜨므로
  인게임은 BMP 기호만 쓴다(☽ · 하르모니아 ♫). 디스코드는 이모지가 잘 나온다.
  기존 8종도 이미 그렇다(오리온 🏹 / ➶).

## 2-B. 딜 스킬 보강 (2026-08-09, 유저 결정)

### 왜 고쳤나

계산상 개인 DPS 가 **헤카테 63 · 하르모니아 44** 로 나왔다(기존 8종은 96~100).

1. **혼자일 때 답답하다.** 탐험·파밍처럼 파티가 없는 시간이 있다.

## 2-C. 하르모니아 — 근접 → **원거리 지원 딜러** (2026-08-09, 유저 결정)

§2-B 를 마치고 「하르모니아는 원거리 딜러로 바꿀 수 없나」는 물음에서 나왔다. 선택지 셋 중
**「원거리 지원 딜러」** 를 골랐다(원거리화만 / **지원 딜러** / 완전 딜러).

### 왜 근접이 문제였나

**버프를 거는 사람이 근접 사거리까지 걸어 들어가야 했다.** 서포터가 제일 서면 안 되는 자리다.
설계 문서에는 「때리는 물건이 아니다」라고 적혀 있었지만, 그건 *때리지 않는 이유*였지
*맞을 자리에 서 있는 이유*는 아니었다.

### 무엇을 바꿨나

| | 전 | 후 |
|---|---|---|
| 평타 | 근접 `weapon(2.5, −2.2)` | **원거리 「음률」** — 초당 3.33발 · 발당 `3.8` · 근접 공격력 속성 **제거** |
| 총합 DPS | 54 | **78** |
| 각성 체력 | 16/19/23/26/**30**칸 | 16/19/22/25/**28**칸 |
| 역할 표기 | 버프·지휘 | **원거리 지원 딜러** |
| 공명 처치중첩 | +5% ×3 (최대 15%) | **+4% ×3 (최대 12%)** |
| R 공격속도 | +25% | **+20%** |
| C 받는 피해 | −15% | **−12%** |
| X 공격력 | +25% | **+20%** |

### 바뀐 뒤 DPS (5성 · 계산값 · §2-B 를 덮어쓴다)

| | 평타 | R | C | X | **단일 표적** | 적 6마리 |
|---|---:|---:|---:|---:|---:|---:|
| 하르모니아 | 68.4 | 3.0 | 5.2 | 1.6 | **78.1** | **126.7** |
| (참고) 헤카테 | 58.4 | 4.1 | 2.4 | 2.4 | 67.3 | 106.1 |

⚠️ **다수전에서 하르모니아가 헤카테를 넘는다(127 vs 106).** 지대 둘이 겹치기 때문이다.
숫자만 보면 뒤집힌 것 같지만, **헤카테의 값어치인 파티 증폭(+15~24%)이 이 표에 안 잡힌다** —
4인 파티 기준 그게 +43~69 다. 그래도 다음 실측 때 둘을 나란히 놓고 볼 것.

※ 음률은 `BoltManager` 투사체라 **바닐라 크리가 안 붙는다**(셀레스티아·파나케이아 평타와 같다).
  위 68.4 는 그래서 크리 배수 없는 값이다 — 근접 유물의 ×1.30 과 직접 비교하면 안 된다.

### 왜 78 이고 97~99 가 아닌가

원거리 셋은 시리우스 97.9 · 솔라리스 97.0 · 셀레스티아 99.1 이다. 하르모니아를 그 대역에
올리면 **딜러 화력 + 공격력 +20% + 공속 +20% + 받는 피해 −12% + 쿨 단축** 을 한 명이 다 갖는다.
그 자리를 피하려면 버프를 크게 깎아야 하는데, 그러면 이 직업이 왜 있는지가 사라진다.
20% 낮은 자리는 **「원거리로 서서 딜도 되지만, 딜만 볼 거면 딜러를 뽑는 게 낫다」** 는 뜻이다.

### 딜을 +44% 늘린 만큼 버프를 −20% 했다

이동속도 계열(공명 +10% · 화음 +20%)은 **안 깎았다.** 그건 파티 화력에 안 잡히고,
「같이 움직이게 만든다」가 이 직업의 정체성 그 자체라 여기서 빼면 남는 게 숫자뿐이다.

### 구현 메모

- 좌클릭은 `RelicActions.firesOnLeftClick()` + `leftAttack()` 로 이미 있던 길이다
  (셀레스티아·솔라리스·파나케이아가 같은 경로). 투사체는 `BoltManager` 재사용.
- **근접 속성을 떼면 `RelicEventHandlers.onRelicAttributes` 의 각성 평타 보정이 자동으로 비껴간다**
  (`base <= 0` 이면 즉시 return — 활·지팡이와 같은 경로). 따로 막을 코드가 없다.
- 스킬의 `dmg()` 에서 무기 공격력 항(`weaponAttack × 0.3`)이 0 이 된다 —
  R 이 30.45 → 29.7 로 미세하게 내려간다. 어픽스·젬 공격력은 그대로 탄다.
- 발마다 음정을 장5음계로 돌린다. 초당 3.3번 같은 소리가 나면 금방 질린다.
- ⚠️ **모델은 아직 낫 재채색이다.** 원거리가 됐어도 자리 맡기 그대로다(`docs/ASSETS.md`).

단일 표적 증가는 5~10 으로 작다. **값어치는 수가 많을 때 나온다** — 공성 수비가 이 서버의 기본
전투 형태라 그쪽이 맞다. 다만 **전부 계산값이다.** 게볼그도 계산 95.5 vs 실측 105.7 로 10%
어긋난 적이 있다(`DECISIONS.md` 2차 보정). §4 의 `/dummy` 실측 전에는 확정하지 말 것.

### 어그로 — 도발 둘 + 평타 위협도 ×1.5 (2026-08-09)

처음엔 **도발 두 개가 전부**였다. 그 사이 구간에는 위협도가 딜러와 똑같이 쌓여서
「탱커인데 몹이 나를 안 본다」가 나올 수밖에 없었다. 그래서 이지스와 같은 자리에
평타 배수를 붙였다(`ThreatManager.NEMESIS_AUTO`).

| | 이지스 | 네메시스 |
|---|---|---|
| 평타 위협도 | **×2.0** | ×1.5 |
| 도발 | R 8칸 4초 · 궁극 16칸 8초 | R 6칸 2초 · C 8칸 4초 |
| 성격 | **붙잡고 있는다** | **순간마다 되찾아온다** |

- **왜 2.0 이 아닌가**: 두 탱커가 같은 값이면 「둘 중 아무나」가 된다. 상시 몫은 이지스가 크고,
  이쪽은 대신 도발 두 개를 짧은 구간에 몰아 걸 수 있다.
- ⚠️ **네메시스의 평타는 느리다**(공격 속도 −2.8). 초당 위협도로 보면 격차는 1.5 대 2.0 보다 크다.
  인게임에서 여전히 안 붙으면 **여기부터 올린다.**
- 스킬 피해에는 배수가 안 붙는다 — `LsDamage.inSkill()` 로 가른다. 두 탱커 모두 같다.

### 치켜들었다 내려찍는다 (2026-08-09)

「누르면 바로 앞에 이펙트가 생겨서 심심하다」는 지적으로 **0.8초 준비 동작**을 넣었다.
마크에는 커스텀 애니메이션이 없으므로 **시간으로** 만든다 — 준비 중엔 바깥에서 안으로 모여드는
고리가 검끝을 따라 올라가고, 끝나면 머리 위에서 발밑까지 한 줄로 떨어진 뒤 바닥이 갈라진다.

- **조준은 «내려찍는 순간»의 시선을 쓴다.** 시전 시점으로 잠그면 0.8초 사이에 보스가 움직였을 때
  「분명 봤는데 헛나갔다」가 된다. 대신 준비 중에 돌아설 수 있으니 맞히기는 오히려 쉽다 —
  대가는 그 0.8초 동안 못 움직이는 것이다.
- **기세는 치켜들 때 태운다.** 내려찍을 때 태우면 준비 0.8초 사이에 패링해서 한 중첩 더 얹는
  짓이 된다.
- **바닥의 금은 «그림»이고 피해 판정선은 눈높이 그대로다.** 내려찍기는 바닥으로 읽혀야 하는데
  판정을 바닥으로 옮기면 공중의 적을 못 때린다. 둘을 갈랐다.
- ⚠️ 준비 중에 무기를 바꾸거나 죽으면 **그대로 사라진다**(쿨은 이미 돌았다). 강철 발의 마무리와
  같은 성질이다.
- ⚠️ 0.8초(`SUNDER_WINDUP = 16`)는 **감으로 잡은 값**이다. 답답하면 12틱까지 줄인다.
- **자세는 PlayerAnimator 로 만들었다** (2026-08-09). `client/anim/SunderAnimation.java` 가
  팔 두 짝 · 상체 · 머리의 회전을 코드로 굽는다 — 블록벤치 자산 없이.
  · 치켜듦 16틱(ease-out, 빠르게 올라가 멎는다) → 내려찍기 5틱(ease-in, «꽂힌다») → 복귀 9틱.
  · **16틱은 `ParryManager.SUNDER_WINDUP` 과 같아야 한다.** 하나를 고치면 반드시 다른 하나도 고친다 —
    안 그러면 그림과 피해가 어긋난다.
  · 1인칭은 `FirstPersonMode.THIRD_PERSON_MODEL` 로 3인칭 모델을 그려 보여준다.
    어색하면 `getFirstPersonMode` 하나만 `NONE` 으로 바꾸면 3인칭 전용이 된다.
  · 레이어 우선순위 **42** — 베터컴뱃 평타 모션과 겹쳐 보이면 올린다.
  · `playeranimator` 가 없는 클라에서는 **자세만 없고 나머지는 그대로 돈다**(`ModList` 로 확인 후 호출).

### 기세는 셋이 나눠 쓴다 (2026-08-09)

R·C·X 가 **같은 자원 하나**를 놓고 다툰다. 이게 이 직업의 유일한 판단이다 —
「지금 버틸까(R·C), 아껴서 터뜨릴까(X)」.

- **소모하면 패시브 배수(+6%/중첩)는 안 붙는다.** X 의 +15%/중첩은 그 6% 를 **대체**하는 값이지
  얹히는 값이 아니다.
### ⚠️ 흘리기 −25% → −15% (2026-08-10)

같은 조작이 **이지스에도 붙으면서** 둘의 몫을 갈랐다.

| | 이지스 | 네메시스 |
|---|---|---|
| 우클릭 | 쥐고 방어 **−25%** | 쥐고 방어 **−15%** |
| 완벽 패링 | ❌ 없다 | ✅ 0.4초 창 |

**그대로 뒀다면 「이지스가 하는 걸 다 하는데 패링까지 있는」 무기가 된다.**
이지스는 «타이밍이 아예 필요 없는 탱커»라 값어치가 두께여야 하고,
네메시스는 «맞추면 무효화»라 못 맞췄을 때가 얇아야 한다.

⚠️ 「못 해도 탱커」의 바닥이 이 줄에 걸려 있었다. 이제 그 바닥은
**R「강철 발」(기세 0 이어도 −20%)이 혼자 진다.** 인게임에서 초보가 잡았을 때
전선이 무너지면 여기부터 되돌린다.

### 피해 감소는 전부 «곱연산»이다

`ParryManager.onParry` 가 `mult` 에 차례로 곱한다 — **더하지 않는다.**
합연산이면 세 개만 겹쳐도 100% 를 넘어 무적이 되므로, 곱연산이어야 상한이 저절로 생긴다.

| 겹친 것 | 계산 | 실제 |
|---|---|---:|
| 우클릭만 | 0.85 | **−15%** |
| 우클릭 + 강철 발(기세 0) | 0.85 × 0.80 | **−32%** |
| 우클릭 + 강철 발(기세 5) | 0.85 × 0.55 | **−53%** |
| 우클릭 + 강철 발(5) + 불굴(0) | 0.85 × 0.55 × 0.90 | **−58%** |

⚠️ **R 과 C 를 둘 다 «가득» 채울 수는 없다.** 기세가 하나뿐이라 R 이 5중첩을 먹으면
C 는 0중첩(−10%)이다. 위 표의 마지막 줄이 현실적인 상한이다.

⚠️ 아틀라스도 같은 방식으로 겹친다: 우클릭(0.75) × 수호 반격(0.60) = **−55%**, 3초.
   `onGuardianParry` 가 별도 핸들러라 둘이 각자 곱해진다.

- **기세 0 에서도 R 과 C 는 둘 다 쓸 수 있다.** R −20%, C −10%. 「못 해도 탱커」의 바닥이고,
  「눌렀는데 아무 일도 안 난다」를 없앤 값이다(2026-08-09 유저 요청으로 C 도 이 꼴이 됐다 —
  그전엔 기세 0 이면 막고 쿨을 돌려줬다).
- **R 과 C 는 세기·길이·대가가 갈린다.** R −20~45% / 3초 / 이동 불가 / 도발 6칸 2초.
  C −10~35% / 6초 / 자유 / 도발 8칸 4초. 급하면 R, 오래 버티려면 C.
- **도발은 쿨에 비례한다** (2026-08-09). 처음엔 R 이 6칸 4초였는데, 12초 쿨짜리가 오래 붙잡으면
  22초 쿨인 C 가 설 자리가 없다. 짧은 쿨은 «급할 때 잠깐», 긴 쿨은 «맡아서 버틴다».
  ⚠️ C 의 8칸 4초는 **이지스 R 과 정확히 같은 값**이다. 원래 「아틀라스보다 작게」가 원칙이었는데
    그 선을 한 곳에서 넘었다 — 이지스는 궁극(16칸/8초)과 상시 위협도 ×2 가 따로 있어
    여전히 «판을 끌어오는» 쪽이지만, 인게임에서 둘이 구분 안 되면 여기부터 내린다.
- ⚠️ **미검증 위험**: X 의 쿨이 90초인데 그때 기세가 비어 있으면 궁극이 기본치로 나간다.
  「R·C 를 아끼는 압박」이 재미가 될지 답답함이 될지는 **인게임에서 봐야 안다.**
  답답하면 X 만 소모를 빼고 패시브 배수로 되돌린다(가장 되돌리기 쉬운 쪽).

### 왜 우클릭인가 — 근접 유물 최초다

`RelicActions` 머리말은 **「우클릭은 비워둔다 — 상자 열기·블록 설치가 방해받지 않게」**가 원칙이고,
실제로 `use()` 를 쓰는 건 **귀환석 · 솔라리스(스코프) · 시리우스(활)** 셋뿐이다.
**근접 유물은 하나도 없다.** 이지스도 안 쓴다.

그럼에도 우클릭으로 가는 이유:

- 패링은 **반응 조작**이다. R/V/C/X 는 스킬 슬롯이라 성급 해금·쿨 표시에 묶여 있고,
  그 자리에 넣으면 스킬 하나를 통째로 잡아먹는다.
- 대검은 `two_handed` 라 어차피 보조손을 못 쓴다.

**대가**: 이 무기를 들고는 상자를 못 열고 블록을 못 놓는다. 공성 중에 문을 열거나 사다리를 놓는
장면이 실제로 불편하면 **R 로 옮기고 「강철 발」을 V 로, 「참격 인계」를 버리는** 순서로 물러선다.

### 아틀라스와 어떻게 갈리나

**2026-08-10 부터 우클릭 「쥐고 방어」는 둘 다 갖는다.** 그래서 갈리는 자리가 옮겨졌다.

| | 아틀라스 | 네메시스 |
|---|---|---|
| **우클릭** | 쥐고 방어 **−25%** · **패링 없음** | 쥐고 방어 **−15%** · **완벽 패링 0.4초** |
| C 스킬 | 「수호 반격」 3초 자동 −40% + 반사 | 「불굴」 기세 소모 −10~35% 6초 |
| 조작 | **타이밍이 아예 필요 없다** | **맞는 순간에 맞춰야** |
| 실패했을 때 | 애초에 실패가 없다 | **−15% 만 받고 그대로 맞음** |
| 성공했을 때 | — | **무효화 + 경직 + 기세** |
| 궁극 | 5초 무적 + 도발 + 아군 보호막 (**생존**) | 대형 일격 + 아군 경감 (**반격**) |

**두께 vs 타이밍**이 이제 한 줄로 정리된다 — 이지스는 패링이 없는 대신 우클릭이 두껍고,
네메시스는 얇은 대신 맞추면 통째로 지운다.

에레보스가 「등 뒤로 돌아야 숫자가 나오는」 숙련형 딜러인 것처럼, **숙련형 탱커**다.

### 「못 해도 탱커」 — 숙련도에 전부 걸지 않았다

두 번째 탱커를 넣는 이유가 **「아틀라스가 없을 때 대신 설 사람」**인데, 그 대체재가 숙련을
요구하면 초보가 잡았을 때 전선이 그대로 무너진다. 그래서 바닥을 깐다:

- **방어력 +5 / 방어 강도 +3** 상시 (이지스 +6/+4 바로 아래) — 패링을 한 번도 못 해도 붙는다
- **체력 40칸** — 크라토스(38)보다 두껍고 아틀라스(42) 바로 아래
- **R 강철 발** — 받는 피해 −40% 를 버튼 하나로. 타이밍 필요 없음

패링을 잘하면 여기에 **주는 피해 +30%** 와 무효화가 얹힌다.

### X 의 아군 경감 범위 — 8칸인 이유

「전 파티」로 하면 하르모니아 「만상의 화음」(24칸 전 아군)과 정면으로 겹친다.
**시전자 주변 8칸**이면 「내 뒤에 서라」가 되어, 멀리서 전체를 덮는 하르모니아와 축이 갈린다.

## 0. 이 직업은 조사와 «맞다» — 그리고 조사의 경고도 같이 지킨다

`CLASS-RESEARCH.md` 관찰 2:

> **히기에이아 1인 과부하.** 힐 + 버프 + 쉴드 + 부활을 혼자 감당한다.
> 3~6인 서버에서 힐러가 결석하면 파티가 성립하지 않는 **단일 장애점**이다.

네메시스를 넣은 논거(관찰 3 — 탱커도 단일 장애점)와 **정확히 같은 꼴**이다.
코드로 확인했다: **회복을 하는 유물은 파나케이아 하나뿐이다.** 하르모니아는 버프만 하고
회복은 안 한다.

**그런데 같은 문서 §6 이 순수 힐러 2종을 명시적으로 반대한다:**

> **역할축 세분화** (예: 힐러를 2종으로 분리) — 파티가 채울 수 없다.

타당하다. 3~6인 서버에 직업이 이미 열둘이다. 순수 힐러가 둘이면 **파나케이아가 오는 날
두 번째 힐러는 할 일이 없고**, 그러면 아무도 안 골라 개발 비용이 사장된다.
**힐러가 없는 날은 여전히 없고, 힐러가 둘인 날만 생긴다** — 단일 장애점이 안 풀린다.

조사가 스스로 제시한 답은 §5 의 **「버퍼 분화 (#19) — ◎ 힐러 단일 장애점 해소」**(2순위)다.
버퍼 자리는 하르모니아가 가져갔지만 **힐은 안 가져갔다.** 그 빈칸을 채운다.

**그래서 「힐러」가 아니라 「힐도 되는 전사」다.**
파나케이아가 있으면 근접 딜·보조로 놀고, 없으면 파티가 굴러가는 최소한의 힐을 댄다.
**항상 쓸 자리가 있어야 실제로 선택되고, 그래야 단일 장애점이 진짜로 풀린다.**

### 왜 케이론인가

케이론은 **전투와 의술을 함께 가르친 켄타우로스**이고, **아스클레피오스의 스승**이다.
아스클레피오스의 딸이 **히기에이아** — 즉 **파나케이아 계보의 «스승»**이다.
두 번째 힐러가 아니라 «먼저 있던 자»로 들어오는 게 로어로도 맞는다.

그리고 그는 **자기 상처만은 끝내 못 고친 치유자**였다(불사라 죽지도 못했다).
그게 이 직업의 기믹 그대로다 — **§2 를 보라.**

### 왜 봉인가 — 철퇴에서 갈아탄 이유 (2026-08-10)

처음엔 **철퇴**로 잡았다가 유저 지적으로 바꿨다. 이유 셋:

**① 로어가 안 맞았다.** 신화의 케이론은 **성직자가 아니라 켄타우로스 스승**이다.
그가 가르친 건 의술·활·음악·사냥이고 **철퇴도 신전도 나오지 않는다.**
「전투 사제」라는 역할 이름에 끌려 서양 판타지 클리셰(철퇴 든 클레릭)를 붙였던 것이다.
켄타우로스에게 맞는 건 **기동**과 **봉**이다.

**② 제일 느린 무기가 「때려야 힐이 나오는 직업」에 붙어 있었다.**
초당 1.0회면 회복이 뚝뚝 끊긴다. 기믹과 손맛이 정면으로 어긋났다.
지금은 **초당 1.8회 — 근접 중 제일 빠르다.**

**③ 「격투가(권갑)」를 따로 만들 필요가 없어진다.** 로스터에 없던 «빠른 연타» 축이
여기로 흡수된다. 14번째를 하나 아꼈다.

**펠리온이라는 이름이 오히려 더 맞게 됐다** — 아킬레우스의 창 자루가 **펠리온산 물푸레나무**였다.
케이론이 직접 잘라 준 나무다.

⚠️ **위험 둘.**
- **에레보스(쌍단검)와 손맛이 겹칠 수 있다.** 둘 다 빠른 근접이다. 축은 다르다 —
  에레보스는 «등 뒤로 도는» 암살자, 이쪽은 «정면에 붙어 버티는» 쪽. 그래도 인게임에서
  「비슷하다」가 나올 자리다
- **지팡이가 이미 둘**이다(우라니아 · 히기에이아). 그 둘은 **원거리 마법 지팡이**라 손맛은
  완전히 다르지만 **모델이 비슷해 보일 수 있다** — 짧고 두껍게, 금속 마감으로 간다

## 2. 핵심 기믹 — 때리면 아군이 낫는다. 나만 빼고

### 패시브 「상처 입은 치유자」 (1성)

**적을 때릴 때마다 반경 12칸에서 가장 다친 아군이 회복된다.**
회복 대상은 자동으로 정해진다(`RelicSkills.weakestAlly` 가 이미 있다).

> ⚠️ **자기 자신은 대상에서 제외된다.**

이 한 줄이 이 직업의 전부다:

- **로어와 정확히 맞는다** — 남은 고치고 자기는 못 고치는 치유자
- **긴장이 생긴다** — 앞에 서야 힐이 나오는데, 앞에 서면 자기가 맞고, 자기는 못 낫는다
- **파나케이아를 대체하지 못하게 막는다** — 혼자서는 오래 못 버틴다.
  「힐러가 없을 때의 보험」이지 「힐러가 필요 없어지는 것」이 아니다

유일한 예외가 **C 「가르침」**(§3)이다. 자기 회복 창이 22초에 한 번, 8초뿐이다 —
«가르친 것이 스승에게 돌아오는» 동안만 열린다.

### 회복량은 «피해 비례»가 아니라 «타격당 고정»이다

| | 값 |
|---|---:|
| 평타 한 대당 회복 | **2.2** (5성 · `healScale` 적용 · 1성 0.9) |
| 공격 속도 | **1.8회/초** |
| **= 지속 회복** | **약 4 HPS** (5성) |

봉으로 갈아타며 **타격당 회복은 내리고 횟수는 올렸다.** 총 HPS 는 그대로 4 다 —
바뀐 건 «묵직한 한 방»이 «끊기지 않는 흐름»이 된 것이다.

**왜 피해 비례로 안 하나.** 크리(×1.5) · 축복 · 전역 배율이 전부 피해에 곱해지므로,
비례로 두면 **회복이 같이 폭주한다.** 회복은 보스 체력을 올려 보정할 수 없다 —
`RelicSkills.healScale` 주석이 이미 같은 이유로 회복 배율을 1.0→2.5 로만 올려뒀다.

**판타지가 「때린 만큼」에서 「때린 횟수만큼」으로 바뀌는데, 그게 낫다.**
봉이 빠르게 오가는 동안 아군 체력이 **끊기지 않고** 차오르는 그림이 더 읽히기도 한다.

### 파나케이아와 무엇이 다른가

| | **파나케이아** (히기에이아) | **펠리온** (케이론) |
|---|---|---|
| 서는 자리 | 뒤 | **앞** |
| 힐 조건 | 조준만 하면 된다 | **적을 때려야 한다** |
| 대상 | 조준한 아군 | 자동(가장 다친 하나) |
| 크기 | 크게 · 즉시 (5성 10 HPS) | 조금씩 · **끊김 없이** (5성 4 HPS) |
| 자기 회복 | 패시브 자기 재생 | **없다** (C 「가르침」 8초만 예외) |
| 적이 없을 때 | 그대로 힐한다 | **힐이 0 이다** |
| 궁극 | 부활 | 힐 폭발 |

**축이 여섯 군데에서 갈린다.** 겹치는 건 「아군 체력이 오른다」 하나뿐이다.

### R 「축성」 — 몰아서 때릴수록 크게 낫는다

한 마리만 때리면 3, 다섯을 쓸면 15. **적을 뭉쳐야 힐이 커진다** —
탱커가 도발로 모아둔 자리가 곧 케이론의 자리가 된다. **파티 시너지가 조작으로 드러난다.**

⚠️ 상한 5마리는 «공성에서 30마리를 쓸어 150 회복»을 막는 장치다. **반드시 상한을 건다.**

### V 「바람 걸음」 — ⚠️ 「자취」를 밟게 하면 안 된다

원안은 「지나간 자리에 회복 자취를 남기고 **아군이 밟으면** 회복」이었다. **그건 거의 안 터진다** —
실전에서 아군이 내 발자국을 따라 걷지 않는다. 화면에는 예쁜데 효과는 0 인 스킬이 된다.

**그래서 「밟는다」를 뺐다.** 6초 동안 **내가 지나가면서 반경 4칸 안의 아군을 그때그때 회복**시킨다.
케이론이 전선을 훑고 지나가는 그림은 그대로고, 효과는 실제로 발생한다.

⚠️ **이동기 슬롯의 «위기 탈출»은 약해졌다.** 다른 유물의 V 는 전부 «순간 이동»이다
(천사의 발걸음 · 그림자 도약 · 질풍 돌진 · 참격 인계 · 엮인 걸음).
이쪽은 6초짜리 **지속 버프**라 즉발로 빠져나오지 못한다.
켄타우로스의 기동이라는 판타지엔 맞지만, **34칸 몸으로 앞에 서는 직업에 탈출기가 없다**는 뜻이다.
인게임에서 「빠져나올 방법이 없다」가 나오면 **앞 1초를 순간 가속(이속 +200%)으로** 바꾼다.

### C 「가르침」 — ⚠️ 여기에 자기 회복을 붙였다

8초간 **주변 아군의 평타에도 전이 회복이 생긴다.** 파티 전체가 잠시 케이론이 된다.

**그런데 원래 자기 회복 창은 C 「감내」에 있었다.** 그걸 빼면 **케이론은 자기 회복 수단이 0 이 된다** —
패시브가 자신을 제외하고, 나머지 넷도 전부 아군 쪽이다. **34칸 몸으로 앞에 서는데 자기 회복이
하나도 없으면, 파나케이아가 없는 날(이 직업이 존재하는 바로 그 날) 케이론이 제일 먼저 죽는다.**

**그래서 「가르침」 동안에는 자기 제외가 풀린다.**
남을 가르치면 **그 제자들의 회복이 스승에게도 돌아온다** — 로어로도 정확하고,
자기 회복 창(22초에 8초)이 유지되고, 유저가 고른 스킬도 그대로 산다.

⚠️ **회복 폭주 위험.** 파티 다섯이 8초간 전이 회복을 하면 HPS 가 통째로 뛴다.
**아군의 전이 회복은 케이론 본인의 절반(5성 1.1)** 으로 잡는다. 그래도 5명이면 +2.75 HPS ×
그들의 공속이다 — **인게임에서 제일 먼저 재볼 숫자 중 하나다.**

### X 「펠리온의 밤」 — ⚠️ 대가를 «반동»에서 «제외»로 바꿨다

10초간 반경 12칸 아군이 **죽지 않는다**(체력 1에서 버틴다). ⚠️ 원안 15초 → **10초**(2026-08-10 유저 결정).

원안엔 「끝나면 막은 피해의 절반을 내가 받는다」가 붙어 있었고 유저가 뺐다.
**빼기만 하면 이건 그냥 파티 무적이다** — 이지스 궁극이 5초 무적, 파나케이아 궁극이
«죽은 뒤» 부활인데, 이건 **애초에 안 죽게** 만든다. 보스전 페이즈 하나를 통째로 지운다.

**그래서 계산이 필요 없는 대가를 넣었다: 케이론 자신은 이 효과를 안 받는다.**

- **패시브와 완전히 같은 규칙**이다 — 남은 살리고 자기는 못 살린다. 로어가 또 한 번 맞는다
- 막은 피해를 세고 되돌리는 복잡한 계산이 사라진다
- **파티는 10초간 불사인데 케이론은 죽을 수 있고, 케이론이 죽으면 즉시 끝난다.**
  적이 앞에 선 사람을 때리는 한, 그 10초는 공짜가 아니다

⚠️ **허공(void) 피해는 제외한다.** 체력 1 로 버텨봐야 다음 틱에 또 맞고, 창이 끝나는 순간
전원이 즉사한다 — 살린 게 아니라 죽음을 미룬 것이다.

## 4. 수치 — **실측 반영 (2026-08-11)**

### 겨누는 값

| | 값 | 근거 |
|---|---:|---|
| 총 DPS | ~~75~~ → **90** | 12종 재조정(`DECISIONS.md` 1-E). 이지스·파나케이아와 같은 대역 |
| 지속 회복 | **4 HPS** (5성) | 파나케이아 10 HPS 의 **40%** — 안 바뀜 |
| 체력 | 34칸 | 힐러(30) 위, 탱커(40·42) 아래 |
| 평타 DPS | **약 54** | `(1+4.6)×5.4 × 1.0 × 1.8` — BC 6타 평균 배율이 정확히 1.0 이다 |

### 실측이 드러낸 것 — **딜 스킬이 R 하나뿐이었다**

앵커 환산 실측 **61.5** (평타 57.0 + 축성 4.4). **평타 비중 93% — 12종 중 1위**다
(파나케이아 81%, 이지스 67%).

V「바람 걸음」은 이동·회복, C「가르침」은 버프, X「펠리온의 밤」은 생존이라 **딜이 나오는
스킬이 R 하나뿐**이었다. 평타를 이론 최대(54.4)로 쳐도 54.4 + 3.7 = **58.1** 이 천장이라,
배수를 걸어도 「평타만 치는 직업」이 그대로 남는다.

### 무엇을 바꿨나

| | 전 | 후 | 결과 |
|---|---|---|---|
| R 축성 | `dmg(stack, 8.0f)` | **`15.0f`** | 관측 37 → **70**, 3.7 → **7.0 DPS** |
| V 바람 걸음 | 회복만 | **+ 맥동 피해** | 0 → **약 4 DPS** |

바람 걸음은 0.5초마다 반경 4칸에 들어간다(6초 = 12회). 한 대는 작지만 **범위 전체**다 —
더미 1기로는 4 DPS 로만 보이고 몹 6기면 24 DPS 몫이다. 헤카테의 낫 다중 타격과 같은 성질이라
`/dummy` 숫자로 판단하면 안 된다.

⚠️ 0.5초 장판이라 `LsDamage.hit` 을 쓰면 무적 프레임을 지워 피해가 폭주한다.
`hitLimited` + **이 스킬 전용 키**(`chironWind`)를 쓴다 — 키를 공유하면 다른 장판의 도장을
덮어써 «남의 피해가 사라진다».

평타 비중 93% → **80%** (파나케이아 81% 와 같은 자리). 남은 몫은 `relicScale 1.290`.

### 「지나가며 벤다」가 컨셉과 어긋나지 않나

봉술 몽크다. 「지나가며 낫는다」에 「지나가며 벤다」를 얹는 건 오히려 자연스럽다 —
스틱스의 그림자 도약이 딜의 14% 를 담당하는 것과 같은 모델이다.

### ⚠️ 제일 큰 위험 — 힐러 둘이면 과잉이다

파나케이아 10 + 케이론 4 = **14 HPS**. `PanaceaStaff` 주석이 적어둔 기준은
「수성전 몹 3마리가 붙으면 초당 약 6이 들어온다」이다. **14 HPS 면 그 압박이 통째로 사라진다.**

- 그래서 케이론 회복을 파나케이아의 **절반 이하**로 잡았다
- 그래도 부족하면 **R 「축성」의 상한**과 **X 「양보」의 60%**부터 내린다 — 지속 회복(4 HPS)은
  이 직업이 존재하는 이유라 마지막에 건드린다
- ⚠️ **둘이 같이 있는 판을 실제로 돌려보기 전엔 아무것도 확정할 수 없다.**

### 위협도 — 이중 계상을 막아야 한다

`ThreatManager` 는 **힐에도 위협도를 매긴다**(`HEAL_FACTOR = 0.5`, 반경 24칸).
케이론은 근접이라 **피해 위협도와 힐 위협도를 둘 다 낸다** — 그대로 두면
**탱커보다 어그로를 끄는 힐러**가 된다.

**제안: 패시브 전이 회복은 위협도를 «만들지 않는다».**
그 회복은 이미 «준 피해»에서 나온 것이고, 그 피해가 이미 위협도를 냈다. 두 번 세는 셈이다.
R·C·X 의 회복은 정상적으로 위협도를 낸다(그건 별도 행동이다).

⚠️ 근거 없는 판단이다. 「케이론이 자꾸 맞는다」면 이대로, 「어그로가 전혀 안 온다」면 되돌린다.

### ⚠️ C 「가르침」의 구현 함정

**아군의 평타에 회복을 붙이는 것**이라 판정 주체가 «남»이다:

- 회복의 «출처»는 여전히 **케이론**이어야 한다 — 축복(`BlessingEffects.healingBy`)과
  위협도가 케이론 몫으로 잡혀야 앞뒤가 맞는다
- 아군이 **범위 밖으로 나가면** 창이 끊겨야 한다. 시전 시점에 «명단»을 고정할지
  매 타격마다 거리를 볼지 정해야 한다 → **매 타격마다 본다**(명단 고정은 8초 동안
  20칸 밖에서도 회복이 나가는 구멍이 된다)
- **두 케이론이 겹치면** 아군 한 대에 회복이 두 번 나간다 → 겹침을 허용할지 정해야 한다

### ⚠️ X 「펠리온의 밤」의 구현 함정

「죽지 않는다」는 **토템(불사의 토템)과 같은 자리**를 건드린다:

- `LivingIncomingDamageEvent` 에서 «이 피해로 죽는가»를 보고 체력 1 을 남긴다.
  ⚠️ `ShieldManager` 보호막·`onSunderGuard` 등 **다른 경감이 먼저 걸린 뒤**여야 한다
- **케이론 본인은 반드시 제외**한다(§3). 여기서 자기를 포함시키면 10초 완전 무적이 된다

# 5성 패시브 2단 — 각성의 마지막 계단 (2026-08-11)

## 0. 왜 5성인가 — TODO 의 「4성」은 낡은 기록이다

`REVIEW.md` 가 「4성 패시브 2단」이라고 쓴 것은 **재분배 이전**의 사다리를 전제로 한다.
그때는 1·3·5성에만 해금이 있어서 2성과 4성이 빈칸이었다. 그런데 재분배(TODO A절, 완료)가
**이미 2성·4성을 채웠고**, 대신 **5성을 비웠다.**

| | 1성 | 2성 | 3성 | 4성 | 5성 |
|---|---|---|---|---|---|
| 재분배 전 | 패시브+기본 | — | 추가 | — | 궁극 |
| 재분배 후 | 패시브+기본 | 이동기 | 추가 | 궁극 | **없음** |

`ls_ascend.js` 머리 주석이 스스로 자백하고 있었다 — *「매 단계에 새 버튼이 생긴다 — 4성까지는.」*
5성 설명은 `모든 힘의 완성`인데 실제로는 배율과 체력만 올랐다.

그대로 4성에 넣으면 4성이 둘이 되고 5성은 그대로 빈다. 그래서 5성이다.

## 1. 왜 열둘 다 딜이 아닌가

**5성은 이미 `피해 ×3.0` 으로 숫자 보상을 다 준다.**
여기서 딜을 또 올리면 2026-08-11 에 12종을 90~114 로 맞춘 목표선
(`RelicEventHandlers.relicScale`)이 통째로 깨지고, 열두 판을 다시 재야 한다.

> **2단은 세지는 게 아니라 달라지는 것이다.**

단일 표적 지속 DPS 기여가 **전부 0** 이다. `/dummy` 로 재도 12종 값이 안 움직인다 —
그게 이 설계의 합격 조건이다.

**설계 중에 두 번 되돌렸다.** 자연스러워 보이는 안이 둘 다 목표선을 건드렸다:

| 처음 생각한 것 | 왜 버렸나 |

| 타이탄 — 거인 보너스 +15% → +25% | **`/dummy` 더미는 최대 체력 100만**이라 거인 살해자가 이미 걸린 채로 쟀다. 타이탄만 104 에서 떨어져 나간다 |
