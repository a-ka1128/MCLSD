## 알아둘 것

- **효과는 전부 공동(共同)이다.** 누가 자원을 냈든 서버 전원에게 적용된다.
  기여도는 명예로만 남는다(마을 화면 하단).
- **1단계도 전부 실효가 있다.** 예전엔 성소1·공방1 이 '상징'이었는데, 가장 싼 단계일수록
  체감이 있어야 다음 단계를 짓고 싶어진다는 판단으로 전부 실제 효과를 붙였다.
- **별빛 축복의 원거리 보정.** 힘(strength)은 근접에만 붙어서, 그대로 두면 오리온·헬리오스·
  우라니아 같은 원거리 가호가 축복을 절반만 받는다. Apotheosis 의 `projectile_damage` 를
  함께 걸어 활·총·지팡이도 같이 세지게 했다.
- **귀환석의 쿨다운은 아이템에 붙는다.** "1시간에 하나씩 지급"이 아니라 아이템 하나의 쿨이 1시간.
  여러 개를 모아도 쿨을 공유하므로 소용이 없고, 원정 중 "지금 쓸까"를 한 번 고민하게 된다.
- **공용 작업대의 추가 산출은 0 개도 나온다.** `0개 33% · 1개 24% · 2개 24% · 3개 19%` (기댓값 +1.29).
  무조건 +1 이면 제련 한 번의 가치가 그냥 2배가 되어 광물 채산성이 통째로 흔들린다.
  3분의 1이 꽝이어야 "가끔 더 나온다"는 보너스로 남는다.
- **정수 게이팅.** 3~4단계는 전부 균열 정수를 요구한다 = 보스를 잡아야 마을이 큰다.
  자원 노가다가 아니라 콘텐츠 진행이 마을 발전 속도를 정한다.
