## 0. 이 직업은 조사와 «맞다» — 9·10번째와 다른 점

`CLASS-9-10.md` §0 은 「조사 권고를 유저 결정이 덮었다」로 시작한다. **이 문서는 반대다.**
`CLASS-RESEARCH.md` 가 직접 꼽은 빈칸을 채운다:

> §3-1 전위 — #4 **자해형 탱커** ❌ 없음 / #5 **회피 탱커** ❌ 없음
>
> §4 관찰 3 — **탱커도 단일 장애점.** 아틀라스 결석 = 전선 붕괴.
> #4·#5 부재가 "대체 탱커 없음"으로 직결된다.

크라토스가 체력 38칸이라 탱커처럼 보이지만, 조사는 그를 **「광전사 · 근접 딜러」**로 진단했다.
방어 도구가 없다 — 도발도 아틀라스만 쓴다(`TauntManager` 호출부 2곳 전부 이지스 스킬).
**두 번째 탱커는 비어 있는 자리가 맞다.**

다만 조사가 적은 #4(자해형)는 유저가 반려했고, 대신 **패링형**으로 간다.
#5(회피 탱커)의 「맞지 않는 것이 방어」를 대검으로 번역한 것에 가깝다.

### 한 문장 기둥

> **맞는 것이 자원이다.**

「받은 걸 돌려준다」가 이름(응보의 여신)과 조작(패링)과 수치(기세)를 한 줄로 꿴다.

### 색 — 알고 고른 것

색상(hue)이 아틀라스 214° · 오리온 216° · 네메시스 220° 로 **사실상 같다.** 파란 계열이 셋이다.
갈리는 축은 채도와 명도다:

| | 색상 | 채도 | 명도 | 인상 |
|---|---:|---:|---:|---|
| 아틀라스 | 214° | 40% | **84%** | 밝고 옅은 하늘빛 |
| 오리온 | 216° | **69%** | 51% | 선명한 파랑 |
| **네메시스** | 220° | **23%** | **43%** | 어둡고 탁한 강철 |

무채색에 가까운 게 「강철」답다는 판단으로 유저가 그대로 채택했다.
**나란히 놓고 안 갈리면 `#4A5A7A`(더 어둡게) 또는 `#5A6480`(보라 쪽)으로 한 칸 더 벌린다.**

## 2. 조작

| 키 | 이름 | 효과 | 쿨 | 해금 |
|---|---|---|---|---|
| **좌클릭** | — | BC `claymore` 3타 (쓸기 ×0.75 → 찌르기 ×1.0 → **내려찍기 ×1.25**) | — | 1성 |
| **우클릭** | **흘리기** | **0.4초 패링 창** · 성공 시 피해 무효 + 공격자 경직 + **기세 +1** / 실패 시 그냥 맞음 | 1.2초 | 1성 |
| 패시브 | **강철의 각오** | 대검 소지 시 **방어력 +5 · 방어 강도 +3** · **기세** 중첩당 주는 피해 **+6%** (최대 5중첩 · 10초) | — | 1성 |
| **R** | **강철 발** | 3초 뿌리내림 — 넉백 무효 + **받는 피해 −40%** · **이동 불가** · 종료 시 반경 5칸 밀어내며 피해 | 12초 | 1성 |
| **V** | **참격 인계** | 대검을 던지고 **그 대검을 잡으며 날아간다** | 9초 | 2성 |
| **C** | **역린** | 5초간 **패링 창 2배** + 패링 성공 시 반격이 4칸 광역으로 | 22초 | 3성 |
| **X** | **일도양단** | 전방 12칸 직선 대형 일격 · 경직 + 방어력 절반 · **이후 5초간 주변 8칸 아군 받는 피해 −25%** | 90초 | 4성 |

### 왜 우클릭인가 — 근접 유물 최초다

`RelicActions` 머리말은 **「우클릭은 비워둔다 — 상자 열기·블록 설치가 방해받지 않게」**가 원칙이고,
실제로 `use()` 를 쓰는 건 **귀환석 · 솔라리스(스코프) · 시리우스(활)** 셋뿐이다.
**근접 유물은 하나도 없다.** 이지스도 안 쓴다.

그럼에도 우클릭으로 가는 이유:

- 패링은 **반응 조작**이다. R/V/C/X 는 스킬 슬롯이라 성급 해금·쿨 표시에 묶여 있고,
  그 자리에 넣으면 스킬 하나를 통째로 잡아먹는다.
- 대검은 `two_handed` 라 어차피 보조손을 못 쓴다.

**대가**: 이 무기를 들고는 상자를 못 열고 블록을 못 놓는다. 공성 중에 문을 열거나 사다리를 놓는
장면이 실제로 불편하면 **R 로 옮기고 「강철 발」을 V 로, 「참격 인계」를 버리는** 순서로 물러선다.

### 아틀라스와 어떻게 갈리나

이지스에도 「수호 반격」(C·3성)이 있다. **같은 물건이 아니다.**

| | 아틀라스 「수호 반격」 | 네메시스 「흘리기」 |
|---|---|---|
| 조작 | 켜두면 **3초 자동** — 타이밍 불필요 | **맞는 순간에 맞춰야** |
| 실패 | −40% 는 받으니 손해 없음 | **그대로 맞음** |
| 성공 | 반사 피해 | **무효화 + 경직 + 기세** |
| 성격 | 안정적 · 누구나 | **숙련도 보상** |
| 궁극 | 5초 무적 + 도발 + 아군 보호막 (**생존**) | 대형 일격 + 아군 경감 (**반격**) |

에레보스가 「등 뒤로 돌아야 숫자가 나오는」 숙련형 딜러인 것처럼, **숙련형 탱커**다.

### 「못 해도 탱커」 — 숙련도에 전부 걸지 않았다

두 번째 탱커를 넣는 이유가 **「아틀라스가 없을 때 대신 설 사람」**인데, 그 대체재가 숙련을
요구하면 초보가 잡았을 때 전선이 그대로 무너진다. 그래서 바닥을 깐다:

- **방어력 +5 / 방어 강도 +3** 상시 (이지스 +6/+4 바로 아래) — 패링을 한 번도 못 해도 붙는다
- **체력 40칸** — 크라토스(38)보다 두껍고 아틀라스(42) 바로 아래
- **R 강철 발** — 받는 피해 −40% 를 버튼 하나로. 타이밍 필요 없음

패링을 잘하면 여기에 **주는 피해 +30%** 와 무효화가 얹힌다.

### X 의 아군 경감 범위 — 8칸인 이유

「전 파티」로 하면 하르모니아 「만상의 화음」(24칸 전 아군)과 정면으로 겹친다.
**시전자 주변 8칸**이면 「내 뒤에 서라」가 되어, 멀리서 전체를 덮는 하르모니아와 축이 갈린다.

## 3. 수치 — **전부 가정치다**

| | 계수 | 5성 한 방 |
|---|---|---:|
| 패링 반격 | `dmg(stack, 6.0f)` | 34 |
| R 종료 폭발 | `dmg(stack, 9.0f)` | 51 |
| C 광역 반격 | `dmg(stack, 4.5f)` | 26 |
| X 일도양단 | `dmg(stack, 26.0f)` | 142 |

**5성 총합 대략 88** (평타 76 + 스킬 12). 8종 파티 평균 96.5 기준 **이지스와 같은 하위 대역**이다 —
탱커라 맞다.

⚠️ **근거가 얇은 곳이 하나 있다.** 스킬 몫 12 중 7 이 「패링을 5초에 한 번 성공한다」는 가정에서
나온다. 그 빈도는 사람마다 다르고, 우리는 아직 한 번도 안 재봤다. **총합의 8% 가 그 가정 위에 있다.**

## 4. 구현 — 거의 다 재활용이다

| 필요한 것 | 어디서 | 비고 |
|---|---|---|
| 평타 3타 콤보 | `bettercombat:claymore` | `data/lsrelics/weapon_attributes/nemesis.json` 한 줄 |
| **패링 창 판정** | `RelicEventHandlers.onGuardianParry` 구조 | `custom_data("parryUntil")` + `LivingIncomingDamageEvent`. **여기만 새로 짠다** |
| 기세 중첩 | `CurseManager` / `HarmonyManager` | 만료 틱만 적는 방식 |
| 방어력·방어 강도 | `LSRelics.guardianAttrs()` | 같은 꼴로 `nemesisAttrs()` |
| V 대검 던지기 | **`JavelinManager.throwSpear`** | 게볼그가 이미 «손에 든 모델을 그대로 띄워» 날린다 |
| V 끌려가기 | `RelicSkills.aegisCharge` | 속도 부여 방식 |
| X 아군 경감 | `SanctuaryManager` 또는 `HarmonyManager.inKnot` | 짧은 지속이라 후자 쪽이 가볍다 |
| 도발 (쓸 거면) | `TauntManager` | 지금 설계엔 없다 — 이지스와 겹쳐서 뺐다 |

### 「경직」은 마크에 없다

`MOVEMENT_SLOWDOWN` 최고 등급 + `setDeltaMovement(0, y, 0)` 으로 근사한다.
헤카테 「재의 결계」가 이미 그 방식이다(`RelicSkills.ashWard`).

### 등록해야 할 곳 (9·10 때 목록 그대로)

`LSRelics`(아이템) · `FateCatalog` · `isRelic` · `CooldownDisplay` · `DummyManager`(이름) ·
`ls_relic` / `ls_fate` / `ls_ascend` / `ls_title` / `ls_migrate` · lang ko·en 각 7키 ·
`discord/post_nemesis.py` + `post_classes.py` 의 `MODULES` · 모델 + 텍스처 · weapon_attributes

각성 체력표(`ls_ascend.js`)에 넣을 값 — 「추가 HP = 목표 칸수 × 2 − 20」:

```js
nemesis:  { 1: 0, 2: 14, 3: 30, 4: 44, 5: 60 }, // 10/17/25/32/40칸 — 패링 탱커
```

## 5. 착수 전에 알아야 할 것

- ⚠️ **아이콘 `⊗` 를 인게임에서 확인할 것.** 마크 기본 폰트는 BMP만 있고, 예전에 🔥 를 골랐다가
  네모로 떠서 갈아엎은 적이 있다(`CLASS-9-10.md` §1 ※). 안 되면 `◈` 가 후보다.
- ⚠️ **모델·텍스처가 없다.** 대검 모델을 새로 구해야 하고, `ASSETS.md` §8 의 라이선스 기준
  (ARR·허락 문구 없는 것은 배포 차단)을 그대로 적용해야 한다.
- ⚠️ **`/dummy` 재보정을 아직 안 했다.** `CLASS-9-10.md` §4 가 「더 추가할 직업이 있으면
  **실측 재보정 전에 전부 확정**하라」고 못박아뒀다. **12번째까지 정하고 나서 한 번에 잰다.**
- 🔎 **곁들여 — 아틀라스 모델을 바꾸면 두 문제가 같이 풀린다.** 지금 `guardian.json` 은
  Royal Shield(방패)라 「검 쓰는 직업이 없다」는 체감의 원인이고(코드상으론 `BulwarkBlade`,
  즉 검이다), 동시에 `ASSETS.md` §8 의 **ARR·허락 없음** 두 건 중 하나다.
  검+방패 모델로 갈면 외형과 라이선스가 한 번에 정리된다.
- 🔎 **`ls_relic.js` 의 조작 설명이 10종 중 8종 낡았다.** 「쉬프트+우클릭」「더블쉬프트」로
  적혀 있는데 실제로는 전부 R/V/C/X 다. 헤카테·하르모니아만 최신이다. `/relic` 에 그대로 뜬다.
