# Last Stardust — 배포 전 체크리스트

> `.mrpack` 을 친구에게 내보내기 **직전에** 훑는 문서. "지금은 켜두고 나중에 꺼야 하는 것"들이 여기 모인다.
> 개발 중 편의를 위해 켜둔 설정이 그대로 배포되면 친구들 화면에 개발용 UI가 뜨거나 진행이 꼬인다.

---

## A. FancyMenu — 타이틀 화면 ⚠️ 가장 잊기 쉬움

경로: `config/fancymenu/`

- [ ] **레이아웃 활성화** — `customization/laststardust.txt` 의 `is_enabled = true`
      *(현재 개발 중이라 의도적으로 `false`. 에디터의 `레이아웃` 메뉴에서 켜는 걸 권장 — 파일 직접 수정은 게임 실행 중이면 덮어써진다)*
- [ ] **상단 커스터마이즈 바 숨기기** — `options.txt` 의 `show_customization_overlay = 'false'`
      *(개발 중엔 `true`여야 에디터에 들어갈 수 있다. 배포본에 남으면 친구 화면 상단에 `커스터마이즈/도구/도움말` 바가 뜬다)*
- [ ] **바닐라 메뉴 음악 끄기** — `options.txt` 의 `play_vanilla_menu_music = 'false'`
      *(안 끄면 우리 BGM `ls_title_bgm.ogg` 와 마크 기본 메뉴 음악이 동시에 재생된다)*
- [ ] **게임 인트로 설정 비우기** — `options.txt` 의 `game_intro_animation_name = ''`
- [ ] **중복 레이아웃 제거** — `customization/` 에 활성 레이아웃이 **하나만** 있을 것
      *(`title_screen_layout.txt` 는 미완성 잔재 → `.bak` 처리)*

### Export 시 반드시 포함할 폴더
- [ ] **`config`** — FancyMenu 레이아웃·에셋(배경/로고/버튼/BGM)이 전부 여기 있다. 빼면 친구 화면은 바닐라
- [ ] **`shaderpacks`** — Rethinking Voxels + 우리 어둠 프리셋 `.txt`. 빼면 무드가 달라짐

> **주의:** FancyMenu 를 모드 목록에서 빼면 커스터마이즈가 **전부 사라진다.** `config/` 는 "그리는 방법"일 뿐,
> 실제로 그리는 주체는 모드다. 리소스팩처럼 파일만 남기면 되는 구조가 아니다.

---

## B. 서버 접속

- [ ] **접속 주소 확정** — 호스트(`localhost`)와 친구(공인 IP/터널)가 다르면 같은 레이아웃을 못 쓴다.
      playit.gg 등으로 **주소 하나로 통일** 권장
- [ ] "이세계 접속" 버튼의 `JoinServer` 액션에 **최종 주소** 입력
- [ ] (선택) `servers.dat` 를 배포에 포함 → 멀티플레이 목록에도 미리 등록된 상태로

---

## C. 개발용 설정 되돌리기

- [ ] `/mobscale auto` — 테스트로 `set` 해둔 강제 티어 해제
- [ ] `/bossdiff export` → 확정 값을 `ls_config.js` 에 반영 후 `/bossdiff reset`
      *(라이브 오버라이드는 월드 리셋 시 사라진다. 파일 값만 영구)*
- [ ] `/dummy clear` — 훈련 더미 제거
- [ ] 테스트로 올린 각성 단계(`/ascend set`)·가호(`/fate reset`) 정리

---

## D. 클라이언트 위생

- [ ] **중복 모드 없는지** — 같은 모드의 두 버전이 동시에 있으면 부팅 실패
      *(전례: Iris 1.8.12 + 1.8.14 동시 존재)*
- [ ] 클라 전용 모드가 `server/mods` 에 섞이지 않았는지 (`MODS.md` 목록 참고)
- [ ] `lsrelics-1.0.0.jar` 이 서버·클라 **동일 버전**인지 (md5 비교)
      *(전례: 2026-07-24 시점에 서버 387,664B / 클라 387,085B 로 서로 다른 빌드가 올라가 있었다.
      마을 화면·유물 입력은 클라와 서버가 같은 패킷 정의를 써야 하므로 어긋나면 조용히 안 먹는다)*
- [ ] **jar 교체는 반드시 게임을 끄고** — 마인크래프트는 부팅 때 mod jar 를 열어 핸들을 붙잡는다.
      켜둔 채 덮어쓰면 그 핸들이 어긋나 **나중에 그 jar 안의 파일을 읽는 순간** 터진다.
      *(전례: 2026-07-25 클라 실행 중 lsrelics 교체 → 접속 시 `damage_type:lsrelics:relic_magic` 에서
      `EOFException: Unexpected end of ZLIB input stream` 으로 서버 접속 실패. 파일 자체는 멀쩡했고 재시작으로 해결.
      부팅은 성공하는데 접속만 실패하는 형태라 원인을 엉뚱한 데서 찾기 쉽다)*
- [ ] **키바인드 충돌 확인** — 마을 관리 `N` · 유물 스킬 `R`(기본) `V`(이동) `C`(추가) `X`(궁극).
      게임 설정 › 조작 › `Last Stardust` 에서 전부 재지정 가능. 마을은 `/town` 명령으로도 열 수 있다
      *(`M` 은 쓰면 안 된다 — Xaero's World Map 기본키다)*
